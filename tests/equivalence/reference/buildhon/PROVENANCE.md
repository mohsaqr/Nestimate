# BuildHON (vendored reference)

The authors' reference implementation of the higher-order network (HON) of Xu, Wickramarathne & Chawla (2016),
"Representing higher-order dependencies in networks", Science Advances 2(5), e1600028, and the parameter-free
BuildHON+ (Saebi, Xu, Kaplan, Ribeiro & Chawla 2020).

- Source: https://github.com/xyjprc/hon, `pyHON/`, commit 2c89ad43911707e3185f18ebe8686d353aa50c83 (2019-10-21).
- Licence: MIT (`LICENSE.txt`, Copyright (c) 2019 Jian Xu).
- Copied unchanged on 2026-11-22 with the owner's approval; only standard-library Python, no network access.
- Used only by the equivalence tests (build-ignored); not part of Nestimate.
